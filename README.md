# Store Customer Management System

A simple command-line application for managing store customers, built with Python and SQL Server.

## Technologies
- Python 3.12
- SQL Server
- pyodbc
- bcrypt

## Project Structure
- main.py : Main menu and program flow
- database.py : Database connection and queries
- customer.py : Customer operations (add, list, search, update, delete)
- auth.py : Registration and login logic

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Run the program:
   python main.py
